# Independent evaluation

Version 0.1.0 has an independent reviewer and a functional smoke test. No matched control comparison has been run.

## Creative and usability checks

Give first-time players a build with a fresh journal and the in-game instructions. Allow three minutes. Record whether and when they make a first observation and find a walkable route around the pond. Count attempts to continue after deep-water movement stops. Have a reviewer score landmark visibility, depth and perceived scale from the opening view and two positions along the route. Record viewport, device and input method. Keep navigation-rate observations separate from automation run times.

Confirm WebGL rendering, keyboard and touch controls, discovery interactions, and journal persistence by rerunning the project test. Browser automation verifies that a known route works. It cannot establish that a new player will discover it.

## Project learning comparison

When enough project memory has accumulated, use two isolated copies of the same pinned project and one task chosen and recorded by an independent reviewer. Give both agents the constitution and equivalent tools, time and runtime. Give Genesis the project memory and project-specific skills. Withhold those materials from the control. Select prompts and scoring before assignment, blind the reviewer to which agent produced each output where feasible, and preserve both outputs alongside build and check logs. Record model and runtime versions, resource budgets, setup deviations, and any inability to keep the two conditions equivalent.

Report completed and failed checks for both conditions, plus time, diagnosed mistakes, and which evidence supports the creative judgment. Changes to the independent protocol require an independent reviewer and belong to a new comparison.
