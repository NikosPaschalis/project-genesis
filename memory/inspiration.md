# External inspiration

When a contribution offers a reusable insight, record its source, the principle it suggests, and a project question it might help answer. Link to reference material when available. Preserve excerpts or assets only when their permissions allow it.

Give each useful observation a disposition: worth testing, deferred until a stated condition, or declined with a short rationale. For experiments, add the result and link any supporting evidence. Keep hypotheses distinct from observations.

Revisit deferred notes when their stated condition arises or when choosing the next playable checkpoint. Use the current creative goals and evidence to decide what merits time. Keep player-facing discussion free of unexplored discoveries and hidden mythology.
