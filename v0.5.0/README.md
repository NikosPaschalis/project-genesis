# The Quiet Reach v0.5.0

Explore a second way across the basin and trace the far shore on foot. The field journal keeps observations in the order you discover them, and the ambient sound changes as you move through the Reach.

Download and extract the ZIP. Start the server described in `PLAY.txt` and open the local address in a WebGL 2 browser. Sound is optional. Rendering speed varies by device and some scenery can be walked through.
